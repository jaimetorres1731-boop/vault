# Vault V4.1 — consolidated release candidate

Preserves V4.0 and the existing localStorage savings schema. Fixes V4.0 widgets mounting into the wrong page after navigation reorganizes the DOM: quick add and homepage customization now live on Dashboard; report in Insights; theme and backup in Settings. Improves mobile spacing and updates offline cache version. Includes existing six-digit PIN gate, transaction tools, customizable dashboard, backup preview, reports, and themes.

IMPORTANT: The PIN does not encrypt browser-stored financial records. Export a backup before deploying. Browser end-to-end testing is required before treating as production-ready.
