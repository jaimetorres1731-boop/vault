# Vault V2.5 — Unified deployment savings release candidate

Contains the complete V2.4 application plus the new deployment-specific enhancements in one upload.

- Payday Planner remains removed from navigation and hidden for backward compatibility.
- Home remains simplified with savings and deployment progress.
- Military Pay, Transactions, Goals, Calendar, Insights, Deployment Expenses and Settings remain separate.
- Savings pace and $5k/$10k/$25k/$50k/$75k/$100k milestones on Goals tab.
- Deployment savings simulator in Insights: adjust monthly contributions and extra expenses without changing saved records.
- Deployment completion report and downloadable CSV including transactions.
- Existing backup, data storage and military pay functionality retained.
- Published-rate assistance remains limited: automatic BAH by ZIP and locality per diem are NOT implemented; use official links and verified manual entries.

Run acceptance tests on the deployed site before treating this as a production release. Export a full backup first. The calculator is for estimates, not an official pay determination.
